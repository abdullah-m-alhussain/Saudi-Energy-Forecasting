# Saudi Household Electricity Forecasting Case Study

## Overview

This directory contains the primary research contribution of this repository: a regional household electricity consumption forecasting framework developed for Saudi Arabia.

The case study focuses on forecasting household electricity consumption across Saudi Arabia's thirteen administrative regions using statistical, machine learning, and hybrid forecasting approaches.

The framework was developed to address the challenges associated with regional electricity forecasting under limited publicly available historical data conditions.

# Research Motivation

Electricity consumption forecasting is essential for energy planning, infrastructure management, and future demand assessment.

Saudi Arabia presents a challenging forecasting environment due to regional differences in:

- climate conditions,
- population characteristics,
- household behavior,
- electricity consumption patterns.

A forecasting approach developed for one region may not necessarily perform equally across all regions.

Therefore, this study investigates forecasting methodologies that can capture regional differences while maintaining a reproducible evaluation framework.

---

# Dataset Development

## Household Electricity Consumption Dataset

The Saudi case study uses regional household electricity consumption data collected from Saudi energy-related sources.

The dataset preparation process includes:

- source identification,
- data extraction,
- data validation,
- regional standardization,
- temporal alignment,
- consistency checking.

The final forecasting dataset represents:

- 13 Saudi administrative regions,
- annual household electricity consumption,
- historical regional observations.

---

# Addressing Dataset Limitations

One of the main challenges identified during the research development was the limited availability of publicly accessible regional household electricity consumption data.

The revised framework addresses this challenge through:

- integration of multiple data sources,
- validation of overlapping observations,
- transparent documentation of preprocessing decisions,
- development of forecasting methods suitable for limited-data environments.

The limitation of historical data availability remains acknowledged; however, the improved dataset construction provides a more reliable foundation for regional forecasting analysis.

## 2. Exploratory Analysis

## 3. Feature Engineering

Forecasting features are generated from historical information only.

Examples include:

- lagged consumption values,
- historical trends,
- rolling statistics,
- regional identifiers.

Feature generation is designed to prevent future information leakage.

---

## 4. Forecasting Models

The study evaluates multiple forecasting approaches.

### Baseline Models

- Naïve forecasting
- Persistence forecasting
- Historical mean
- Moving average

### Statistical Forecasting

## ARIMA

ARIMA is included as a traditional statistical forecasting benchmark.

### Machine Learning Models

The hybrid framework combines forecasting information from multiple models to investigate whether integrated approaches can improve prediction performance.
